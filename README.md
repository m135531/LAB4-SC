# SE-314 Lab 04 - Git and JUnit

## Included
- `src/rules/RulesOf6005.java` - completed policy method and runnable `main`.
- `test/rules/RulesOf6005Test.java` - JUnit 4 tests covering distinct policy rules.
- `pom.xml` - JUnit dependency and build configuration.
- `GIT_COMMANDS.txt` - commands to demonstrate Git clone/init, status, add, commit, branch, merge, log, and push.
- `Lab 04 - Completed Report.docx` - report with explanations and screenshot checklist/placeholders.

## Eclipse
Import the folder as an existing Maven project (or use the course starter project and copy the two Java files into its `rules` package). Run `RulesOf6005.java` as a Java Application and `RulesOf6005Test.java` as a JUnit Test.

## Important before submission
Replace every `[INSERT YOUR SCREENSHOT ...]` placeholder in the report with your own screenshots from your machine. The lab rubric explicitly requires screenshots and an in-lab demonstration. Also use your own repository URL and push your own commit history.
